# Add a browser

**TV Bro** is the browser used in this setup. It supports TV remote navigation. Get it from its [official project/releases](https://github.com/truefedex/tv-bro) or official Play Store listing where available.

1. Install the official app.
2. Open All Apps in TV Refresh.
3. Select TV Bro and press OK.
4. Open an ordinary website to check loading and controls.
5. To add it to the dock, hold OK on its tile and choose Add to favorites.

The example TV uses the System WebView build. It needs a functioning Android System WebView. TV Refresh does not bundle a browser or bypass streaming subscriptions and DRM restrictions.
