# Contribute

For a bug, include TV model, Android version, TV Refresh version, exact action, expected result and actual result. Remove personal information from screenshots and logs.

For another TV, start with a read-only inventory. Describe input handling and reviewed packages. Do not submit universal bulk-uninstall lists or private backups.

Retain license notices and run [the focused checks](docs/build.md). UI changes need an actual hardware screenshot or clearly labeled emulator capture. Never include signing keys, ADB credentials, tokens or account data.
