# Changelog

## 1.0 — First public release

- Five favorites in a floating dock, All Apps and original app artwork.
- Remote-friendly focus, large selected labels and stable long-press menus.
- Return to the same All Apps tile and scroll position; Home returns to favorites.
- Inputs, Wi-Fi, Settings, Themes and a rotating fan cleaner.
- Cache trimming and eligible background task closure without force-stop.
- Genie-like wisps swooping into the fan icon.
- Color themes, dated Telugu festival themes and brief manual celebrations.
- Auto screensavers, drifting clock and optional Aerial Views integration.
- Step-by-step setup, backup, DNS, browser and recovery guides.

Private development builds used earlier version labels. The public version starts at 1.0; Android's internal versionCode stays higher to allow updates to the test TV.
